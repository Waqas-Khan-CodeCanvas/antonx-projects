Lesson 4 — Auth & protected APIs

Log in, store a token in localStorage, then send Authorization: Bearer <token>. Compare 401 (not logged in) vs 403 (logged in but not allowed).

Student student / 1234
Admin admin / 1234
Headers with fetch and axios 
// after login
localStorage.setItem("token", token);

// fetch
fetch("/api/me", {
  headers: { Authorization: `Bearer ${localStorage.getItem("token")}` },
});

// axios (one request)
axios.get("/api/me", {
  headers: { Authorization: `Bearer ${localStorage.getItem("token")}` },
});

// axios default for all later calls
axios.defaults.headers.common["Authorization"] = `Bearer ${token}`;

2. Protected calls

  • GET /api/me — any valid token

Try this sequence: (1) Call /api/me with no token → 401. (2) Login as student → call /api/me → 200. (3) Call admin stats → 403. (4) Logout, login as admin → admin stats → 200.
