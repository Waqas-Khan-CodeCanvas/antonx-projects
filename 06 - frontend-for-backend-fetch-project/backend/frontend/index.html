Fetch & Axios Student Lab

Practice real HTTP calls with plain HTML/JS against a local Express API. You will use fetch, then axios, then protect routes with a Bearer token. Open DevTools → Network (filter Fetch/XHR) for every request.

Start the server: in the project folder run npm install then npm start, and open http://localhost:3000.

Lessons (follow this order)

  • 1 Fetch GET List and get-one · async/await · res.ok · res.json()
  • 2 Fetch CRUD POST · PUT · PATCH · DELETE · Content-Type · JSON.stringify
  • 3 Axios CRUD Same APIs with axios · response.data · automatic errors
  • 4 Auth & protected routes Login · localStorage · Bearer · 401 vs 403
  • ★ API Playground Free practice with fetch or axios for any method

API cheat sheet

Method Path Auth Notes
GET /api/products Public List products
GET /api/products/:id Public One product (404 if missing)
POST /api/products Public Body { "name", "price" } → 201
PUT /api/products/:id Public Full replace { "name", "price" }
PATCH /api/products/:id Public Partial update
DELETE /api/products/:id Public Delete product
POST /api/auth/login Public Body { "username", "password" }
GET /api/me Bearer Current user
POST /api/orders Bearer Body { "productId", "quantity" }
GET /api/admin/stats Bearer + admin 403 for non-admin
GET /api/error Public Always 500 (error practice)

Response shape

Success

{ "data": { ... } }

Error

{ "error": "Human readable message" }
Remember: fetch does not throw on HTTP 404/500 — only network failures throw. You must check response.ok. Axios treats non-2xx as errors by default.

Data is in-memory and resets when you restart the server. Tokens are teaching fakes (token-<id>-<role>), not production JWT.
