Lesson 1 — Fetch GET

Load products with the built-in fetch API. Focus: async/await, checking response.ok, and parsing JSON.

Pattern to remember 
const res = await fetch(`${API_BASE}/api/products`);
if (!res.ok) {
  const err = await res.json();
  throw new Error(err.error || `HTTP ${res.status}`);
}
const json = await res.json(); // { data: [...] }
Open DevTools → Network → Fetch/XHR before clicking buttons. Inspect status, response body, and timing (the API adds ~300ms delay on purpose).
