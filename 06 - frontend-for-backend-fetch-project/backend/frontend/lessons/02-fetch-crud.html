Lesson 2 — Fetch CRUD

Create, replace, patch, and delete products. You must set Content-Type: application/json and JSON.stringify the body yourself.

POST / PUT / PATCH pattern 
const res = await fetch(`${API_BASE}/api/products`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "Book", price: 10 }),
});
const json = await res.json();

Create — POST

POST /api/products

Replace — PUT

PUT /api/products/:id (full object required)

Partial — PATCH

PATCH /api/products/:id (send only fields to change)

Delete — DELETE

DELETE /api/products/:id (no body needed)

Response
