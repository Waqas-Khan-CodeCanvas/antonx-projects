Lesson 3 — Axios CRUD

Same product API as Lesson 2, using axios (CDN). Notice: body is a plain object, JSON header is automatic, and failed status codes go to catch.

Axios vs fetch (same jobs) 
// GET
const { data } = await axios.get(`${API_BASE}/api/products`);

// POST — object becomes JSON automatically
const created = await axios.post(`${API_BASE}/api/products`, { name: "Book", price: 10 });
// created.data  →  { data: { id, name, price } }

// errors (404, 500, …) throw — use try/catch
try {
  await axios.get(`${API_BASE}/api/products/9999`);
} catch (err) {
  console.log(err.response.status, err.response.data);
}
